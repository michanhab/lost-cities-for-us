# ロストシティ オンライン (Lost Cities Online)
2人でオンライン対戦できる、戦略型探検カードゲーム Web アプリケーション

---

## 🌟 特徴・機能一覧

### 1. ゲームルール完全実装
- **5つの探検エリア**: 火山 (赤) / 海洋 (青) / 密林 (緑) / 砂漠 (黄) / 雪山 (白)
- **合計60枚のカード**: 各色12枚（数字カード 2〜10 の9枚 ＋ 投資カード 3枚）
- **厳密なルールバリデーション**:
  - 数字カードは昇順（小さい順）でのみ配置可能
  - 投資カードは数字カードを出す前に限り配置可能（最大3枚）
  - STEP 1（配置 または 捨て札）➔ STEP 2（山札 または 捨て札から引く）の2段階ターン進行
  - 直前に自分が捨てたカードの即時引き戻し禁止
  - 手札は常に8枚に管理
- **得点自動計算**:
  - 基本得点: `(数字合計 − 20点)`
  - 投資倍率: `投資0枚: ×1` / `1枚: ×2` / `2枚: ×3` / `3枚: ×4` (マイナス点も倍率適用)
  - ボーナス: 1エリアに8枚以上配置で `+20点`
  - カード0枚のエリアは0点

### 2. オンライン＆オフライン対戦機能
- **友達と対戦**: ルーム作成、招待URL発行、LINE共有、ワンクリック参加
- **ランダム対戦**: 全国プレイヤーとの即時マッチング
- **CPU練習対戦**: 1人でもすぐに遊べる高度なAI練習モード
- **初心者チュートリアル**: ステップバイステップの図解・体験型チュートリアル
- **再戦・次ラウンド機能**: 3ラウンド制（累計スコア競い合い）＆ 1ラウンド制対応

### 3. スマートフォン＆PC両対応の洗練されたUI/UX
- iPhone Safari / Android / PCブラウザに最適化された縦型カードゲームレイアウト
- 手札タップ選択 ➔ 配置可能エリア・捨て札のパルスグローハイライト
- Web Audio APIによる高品質な効果音（カードめくり音、配置音、ドロー音、勝利ファンファーレ）
- スコア予想アシスト、プレイ履歴ログ、戦績（勝率・最高得点）のローカル保存

## 🚀 起動方法

### 前提条件
- Python 3.9 以上
- 依存パッケージ: `fastapi`, `uvicorn`, `websockets`

```bash
# パッケージのインストール（初回のみ）
pip install fastapi uvicorn websockets

# サーバー起動
python server.py
```

ブラウザで `http://localhost:8000` を開くとゲームを開始できます。
ローカルネットワーク内のスマートフォン（iPhone / Android）からも `http://<PCのローカルIP>:8000` で接続して対戦可能です。
